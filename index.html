GitHub PAT

PAT 只負責控制台改設定、改監控頻率、讀 GitHub 用量、儲存模擬狀態、觸發連線測試。只留喺呢個分頁，唔會寫進倉庫。

  1. 開啟 建立 Fine-grained token
  2. Repository access 只勾 iphone-monitor
  3. Permissions：Contents、Actions、Workflows 都設 Read and write（Workflows 用來改 watchdog 時段）
  4. 用量會讀呢個倉庫本月 Actions 跑咗幾多次（要有 Actions 讀取）。GitHub 官方 Billing API 唔支援 Fine-grained PAT，所以即使 Plan 設咗 Read，帳戶總用量多數仍然讀唔到
  5. 若要由控制台覆寫通訊 Secret，再加 Secrets Read and write
  6. 把 github_pat_… 貼入下面（唔好用 Telegram bot token）
GitHub 唔會把 Secret 值讀返畀網頁。PAT 最多睇到「有冇呢個名」。
更新 Telegram 憑證（可選，留空＝唔改）

呢兩個欄位唔會自動載入現有 Secret 值。 你已經喺 Settings → Secrets 加咗 TELEGRAM_BOT_TOKEN / TELEGRAM_CHAT_ID， 就唔使再填。得要換 token 或改 chat id 先填然後儲存。通知只經 Telegram。
