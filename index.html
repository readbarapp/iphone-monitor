GitHub PAT

PAT 只負責控制台改設定、改監控頻率、觸發測試通知。只留喺呢個分頁，唔會寫進倉庫。

  1. 開啟 建立 Fine-grained token
  2. Repository access 只勾 iphone-monitor
  3. Permissions：Contents、Actions、Workflows 都設 Read and write（Workflows 用來改 cron）
  4. 若要由控制台覆寫通訊 Secret，再加 Secrets Read and write
  5. 把 github_pat_… 貼入下面（唔好用 Telegram bot token）
GitHub 唔會把 Secret 值讀返畀網頁。PAT 最多睇到「有冇呢個名」。
更新通訊憑證（可選，留空＝唔改）

呢三個欄位唔會自動載入現有 Secret 值（GitHub 唔提供讀返）。 你已經喺 Settings → Secrets 加咗 TELEGRAM_BOT_TOKEN / TELEGRAM_CHAT_ID / DISCORD_WEBHOOK_URL， 就唔使再填。得要換 token、改 chat id，或者第一次用控制台寫入，先填然後儲存。

變更後請按儲存，系統會用 GitHub REST API 更新 config.json。
